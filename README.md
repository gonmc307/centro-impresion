# Centro de Impresión (APK)

1. Creá una cuenta gratis en github.com y un repositorio nuevo (privado está bien).
2. Subí TODO el contenido de esta carpeta (incluida la carpeta oculta .github).
3. Entrá a la pestaña "Actions" > "Compilar APK" > "Run workflow". Tarda unos 4 minutos.
4. Cuando termine, abrí esa ejecución y bajá "centro-de-impresion-apk" (zip con app-debug.apk).
5. Copiá el APK al celular, tocalo e instalalo (permití "instalar apps de origen desconocido").
